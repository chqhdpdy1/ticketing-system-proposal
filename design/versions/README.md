# 설계 버전 스냅샷 (design/versions)

이 폴더는 **설계의 과거 버전을 읽기 전용으로 보존**합니다.

## 규칙

- `design/current/` 가 항상 **최신 설계**입니다. 작업은 여기서 합니다.
- 설계에 **의미 있는 변경**(구조·핵심 결정이 바뀜)을 하기 **전에**,
  현재 `design/current/` 를 아래 형식의 폴더로 복사해 스냅샷을 남깁니다:
  ```
  design/versions/v<major>.<minor>-<YYYY-MM-DD>/
  ```
  예: `v1.0-2026-09-29/`, `v1.1-2026-10-15/`, `v2.0-2026-11-01/`
- 스냅샷 폴더 안의 파일은 **수정하지 않습니다** (그 시점의 기록).
- 무엇을/왜 바꿨는지는 최상위 `../../CHANGELOG.md` 에 기록합니다.
