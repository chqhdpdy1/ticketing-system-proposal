# [v2.0 설계 리팩터링] — 2026-10-31

## 변경 (What)

- Redis 재고·write-behind 대신 PostgreSQL 단일 거래 원장.
- 모듈러 모놀리스로 단순화, 별도 Gateway/Queue 서비스/Worker 제거.
- 물리 Seat와 회차별 StockUnit을 ScreeningSeat로 분리.
- Hold의 잘못된 UNIQUE(stock_unit_id,status)를 ACTIVE 부분 인덱스로 교체.
- 잠금 순서·잠금 후 DB 시각·만료/결제 경쟁·holdId 기반 복원 규칙 정의.
- 단일 좌석·결정적 로컬 Mock 결제·동기 발권으로 1차 범위 제한.
- 미결제 해제와 결제 후 취소·환불을 구분, 후자는 보류.
- 멱등 요청의 키 범위·본문 불일치·응답 유실 복구 정의.
- 선착순을 접수 순서 기반 입장 권한으로 한정하고 Redis 유실 시 epoch 재접수 정책 명시.
- ADR 및 정확성·장애·성능 검증 계획 추가.
- README·PROJECT_STATE·제출 Markdown을 같은 설계 기준으로 갱신.

## 이유 (Why)

DB Outbox로 Redis와 DB 사이의 원자성을 보장한다는 잘못된 설명을 제거한다. 1인 팀이 구현·검증 가능한 크기로 줄이고, 기술 나열보다 거래 불변식과 장애 결과를 명확하게 한다.
