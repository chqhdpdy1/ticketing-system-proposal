# Ticketing System — 재사용 가능한 선착순 판매 엔진

판매 이벤트, 대기열, 수량 선점, 주문·Mock 결제를 공통 REST API로 제공하는 국민대학교 Software Architecture Term Project입니다. 영화관 예매와 굿즈 판매는 같은 엔진을 사용하는 두 시연입니다.

## 현재 설계

- [v3 설계 및 HW3 원고](design/current/06-reusable-sales-engine-v3.md)에 요구사항, UML, 클래스별 품질 매핑, 배치도, 참조 구조를 정리했습니다.
- 좌석은 총수량 1인 판매 항목, 굿즈 옵션은 총수량 N인 판매 항목입니다. 두 화면은 동일한 선점·주문 API를 사용합니다.
- PostgreSQL에서 거래를 확정하고 Redis에서 대기 순번과 입장 권한을 관리합니다. 확정 이벤트를 받아 각 시연의 어댑터가 티켓이나 수령증을 발급합니다.
- 기존 HW1 제출본과 v2 설계 문서는 이전 모델과 결정의 기록입니다. 구현 기준은 v3 원고입니다.
